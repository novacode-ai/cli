# @novacode-ai/cli

> **🚀 COMING SOON: The executable app for the Nova Code AI ecosystem.**

This is the main executable for Nova Code, an autonomous Agentic AI CLI. 

Nova Code supports both **Cloud Models** (OpenAI, Anthropic) and **Local Models** (Ollama, LMStudio), allowing you to run a full AI software engineer directly in your terminal.
